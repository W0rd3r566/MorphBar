# MorphBar

**Нативная Dynamic Island для Android в стиле Google Pixel.**  
Kotlin · Jetpack Compose · Material 3 Expressive · Android 12+

> **Статус:** экспериментальная версия. Начинаем с работающего ядра, а не макета.

## Возможности первой версии

- Плавающая капсула вокруг выреза камеры, автоматически учитывающая геометрию дисплея.
- Управление активной музыкой: обложка, название, пауза, следующая/предыдущая песня и прогресс.
- Ненавязчивые уведомления и индикация зарядки.
- Жесты, пружинные анимации, цвета Material You и настройка положения.
- Быстрое отключение из шторки.
- Без аккаунтов, рекламы, аналитики и разрешения **INTERNET**.

## Скачать APK

Открой [Actions → Android APK](../../actions/workflows/android.yml), выбери успешную сборку ветки `main` и скачай артефакт `MorphBar-debug`. APK собирается автоматически после обновления исходников.

## Первое включение

1. Установи debug APK и открой MorphBar.
2. Разреши «Поверх других приложений» и «Доступ к уведомлениям».
3. Включи капсулу внутри приложения.

⚠️ Это экспериментальная сборка. На Android 17 возможны ограничения наложений поверх строки состояния. Доступ к уведомлениям даёт приложению возможность читать их содержание — предоставляй его только сборке из доверенного исходного кода.

## Сборка

Требуются Android SDK API 37 и JDK 17:

```bash
./gradlew :app:assembleDebug
```

MorphBar основан на открытом проекте [Islet](https://github.com/dylanneve1/islet) авторства Dylan Neve и сохраняет его архитектуру работы с камерой, оверлеем, уведомлениями и медиа-сессиями. Исходный код Islet распространяется по **Apache License 2.0**. См. [LICENSE](LICENSE) и [NOTICE](NOTICE).

Этот репозиторий — самостоятельная модификация: изменены название, package/application ID, пользовательские строки, настройки сборки и CI. Следующие версии будут расширять дизайн и функции.
